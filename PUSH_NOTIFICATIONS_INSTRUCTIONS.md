# Push-уведомления: как устроены и как включить

## Как это работает

1. **Подписка устройства** (`js/fcm.js`). Колокольчик 🔔 рядом с именем открывает уведомления; там кнопка «🔔 Включить push на этом устройстве».
   После разрешения браузера регистрируется `sw.js`, Firebase выдаёт токен устройства, и токен
   сохраняется в базе: `fcm_tokens/<uid>/<ключ устройства>`. При выходе из аккаунта токен этого устройства удаляется.
2. **Событие**. Программа добавляет уведомление в `atelier_data/helperNotices`: новая задача, «сдал на проверку»,
   задача принята, возвращена или просрочена, штраф, выплата, опоздание. Закупка и нехватка на складе — только в программе, без push.
3. **Пока программа открыта** (`announceNewNotices` в `js/app.js`) новое уведомление показывается сразу:
   на экране — всплывающей подсказкой, в фоновой вкладке — системным уведомлением.
4. **Когда программа закрыта** — бесплатная отправка через GitHub Actions (`.github/workflows/push.yml`
   запускает `functions/github-sender.js` раз в 5 минут). Отправитель находит новые уведомления и шлёт push
   на все устройства адресата: для `admin` — на устройства обоих админов, для email — на устройства этого помощника.
   Что уже отправлено, он помнит в `push_state` в базе.
5. **Показ** (`sw.js`). Push появляется даже при закрытой программе. Нажатие открывает программу.
   Если программа уже показала это уведомление сама, push заменит его, а не добавит второе.
6. **Утренняя сводка** в 9:00 по Новосибирску приходит админам: заказы со сроком сегодня, задачи помощников
   на сегодня и задачи на проверке. Если сообщить нечего, сводка не отправляется.

Кому и что отправлять, решает `functions/push-logic.js`. Эту логику и отправителя проверяют автотесты (`отладка`, `npm test`).

**Задержка.** GitHub запускает расписание не точно: обычно push приходит через 5–15 минут, иногда позже.
**60 дней.** Если в репозитории 60 дней не было коммитов, GitHub отключает расписание и присылает письмо.
Включить снова: GitHub → вкладка **Actions** → «Push-уведомления» → **Enable workflow**.

## Как включить (один раз)

### 1. Ключ VAPID — уже вставлен в `js/fcm.js`

Он из Firebase Console → Project settings → Cloud Messaging → Web Push certificates.

### 2. Ключ сервисного аккаунта → секрет на GitHub

С этим ключом отправитель читает базу и шлёт push. **Ключ секретный**: он даёт полный доступ к проекту Firebase.
Не пересылайте его в мессенджерах и не кладите в папку программы.

1. Firebase Console → проект **auto-atelier-1486d** → ⚙️ **Project settings** → вкладка **Service accounts**.
2. Внизу нажмите **Generate new private key** → **Generate key**. Скачается файл `auto-atelier-1486d-firebase-adminsdk-….json`.
3. Откройте репозиторий на GitHub: https://github.com/aleksandraovcaruk37407-pixel/------------final
   → **Settings** → слева **Secrets and variables** → **Actions** → **New repository secret**.
4. **Name**: `FIREBASE_SERVICE_ACCOUNT`.
   **Secret**: откройте скачанный файл в Блокноте, выделите всё (Ctrl+A), скопируйте и вставьте целиком, от `{` до `}`.
5. Нажмите **Add secret**. Скачанный файл затем удалите (и из «Корзины»).

### 3. Проверить

GitHub → вкладка **Actions** → «Push-уведомления» → **Run workflow**.
При первом запуске в журнале будет «Первый запуск: существующие уведомления отмечены как отправленные» — так и должно быть.
Затем в программе нажмите «🔔 Включить push» и «Проверить». Push придёт со следующим запуском расписания.

## Если когда-нибудь будет тариф Blaze

В `functions/index.js` есть то же самое на облачных функциях Firebase — push приходит сразу, без задержки.
Выкладка: `firebase deploy --only functions`. **Включайте что-то одно**: после выкладки функций отключите
расписание GitHub (Actions → «Push-уведомления» → ⋯ → **Disable workflow**), иначе push будут приходить дважды.

## Ограничения

- **iPhone/iPad**: только iOS 16.4 и новее и только если программа добавлена на экран «Домой»
  («Поделиться» → «На экран Домой») и открыта оттуда. Программа сама показывает эту подсказку.
- **Android и компьютер**: Chrome, Edge, Firefox, а также установленное приложение.
- Если человек запретил уведомления, снова разрешить их можно только в настройках сайта в браузере.
- Push включается на каждом устройстве отдельно.
