# 🔔 PUSH-УВЕДОМЛЕНИЯ — ПОЛНАЯ ИНСТРУКЦИЯ

## ✅ Что уже сделано

1. **Service Worker** (`sw.js`) — обрабатывает push-уведомления когда приложение ЗАКРЫТО
2. **FCM модуль** (`js/fcm.js`) — регистрирует Service Worker, запрашивает разрешения, сохраняет токены
3. **Cloud Function** (`functions/index.js`) — отправляет ежедневные утренние уведомления в 8:00 UTC (11:00 MSK)
4. **index.html** — подключён FCM, убран код, удалявший Service Worker
5. **app.js** — инициализация FCM при загрузке
6. **manifest.json** — обновлён для PWA

## 🚀 ЧТО НУЖНО СДЕЛАТЬ (5 шагов)

### ШАГ 1: Получить VAPID ключи (5 минут)

1. Откройте Firebase Console: https://console.firebase.google.com/
2. Выберите проект: **auto-atelier-1486d**
3. Нажмите **⚙️ Settings** (шестерёнка) → **Project settings**
4. Перейдите на вкладку **Cloud Messaging**
5. Прокрутите вниз до **Web configuration**
6. Нажмите **Generate Key Pair**
7. Скопируйте **VAPID private key** (начинается с `BAnq...`)

### ШАГ 2: Вставить VAPID ключ в код

Откройте `js/fcm.js` и найдите строку:
```javascript
vapidKey: 'BAnq3eTTqFV6RmGMCbN6A84jbJMXJ1rO3BKeMYg3Vt0pS2y4fGhJKlMnOpQrStUvWxYz1234567890...'
```

Замените на ваш реальный VAPID ключ из Шага 1.

### ШАГ 3: Получить Server Key (для отправки push)

1. В той же вкладке **Cloud Messaging**
2. Найдите **Credentials**
3. Скопируйте **Server key** (начинается с `AIza...`)

### ШАГ 4: Установить Firebase CLI

```bash
npm install -g firebase-tools
```

Если npm не установлен — скачайте Node.js с https://nodejs.org/

### ШАГ 5: Деплоить Cloud Functions

```bash
# 1. Войти в Firebase
firebase login

# 2. Инициализировать Functions (если ещё не сделано)
cd functions
npm install

# 3. Вернуться в корень проекта
cd ..

# 4. Инициализировать Firebase (если ещё не сделано)
firebase init functions
# Выберите:
# - Use an existing project: auto-atelier-1486d
# - Directory to set up: functions
# - TypeScript: No
# - ESLint: No
# - Install dependencies: Yes

# 5. Деплоить Functions
firebase deploy --only functions
```

## 📱 Как это работает

### Когда приложение ОТКРЫТО:
1. Пользователь заходит на сайт
2. Браузер показывает: "Авто-ателье хочет отправлять уведомления"
3. Пользователь нажимает **Разрешить**
4. Токен сохраняется в базу Firebase (`fcm_tokens/{userId}/browser`)
5. Cloud Function отправляет push-уведомление через FCM API

### Когда приложение ЗАКРЫТО:
1. Cloud Function запускается каждый день в 8:00 UTC (11:00 MSK)
2. Получает все токены админов из базы
3. Формирует уведомление:
   - 💰 Обязательные платежи на сегодня
   - 📋 Заказы на сегодня
   - 📅 Записи в календаре
   - 👥 Задачи помощников
4. Отправляет через FCM API
5. Service Worker показывает системное уведомление
6. Пользователь видит уведомление даже когда браузер закрыт

## ⚙️ Настройка времени отправки

Откройте `functions/index.js`, найдите строку:
```javascript
exports.dailyMorningNotification = functions.pubsub.schedule('0 8 * * *').onRun(async (context) => {
```

Формат: `минута час день_месяца месяц день_недели`

Примеры:
- `0 8 * * *` — каждый день в 8:00 UTC (11:00 MSK)
- `0 9 * * *` — каждый день в 9:00 UTC (12:00 MSK)
- `0 7 * * 1-5` — Пн-Пт в 7:00 UTC (10:00 MSK)
- `0 0 * * *` — каждый день в 0:00 UTC (3:00 MSK)

После изменения — деплойте Functions:
```bash
firebase deploy --only functions
```

## 🔧 Решение проблем

### Проблема: "Разрешение уведомлений: denied"

**Решение:**
1. Откройте настройки браузера
2. Найдите "Уведомления"
3. Найдите ваш сайт
4. Измените на "Разрешить"

### Проблема: Push не приходит когда приложение закрыто

**Проверки:**
1. ✅ Service Worker зарегистрирован? (откройте chrome://serviceworker-internals/)
2. ✅ Manifest подключён? (откройте network tab, ищите manifest.json)
3. ✅ HTTPS? (push работает только на HTTPS)
4. ✅ Разрешение получено? (откройте console, ищите "[FCM] Разрешение уведомлений: granted")

### Проблема: Cloud Function не запускается

**Проверки:**
1. ✅ Firebase CLI установлен? (`firebase --version`)
2. ✅ Functions деплоятся? (`firebase deploy --only functions`)
3. ✅ Нет ошибок в логах? (Firebase Console → Functions → Logs)

### Проблема: "Invalid VAPID key"

**Решение:**
1. Убедитесь, что VAPID ключ вставлен правильно
2. Проверьте, что ключ не обрезан
3. Пересгенерируйте ключи в Firebase Console
